# 失败信息就是规格

日期 2026-10-17

## 从两组对照说起

同一个首轮失败状态，同一个中性反馈，只改失败信息的信息量，结果差得很远。

第一组把隐藏测试的断言原样贴进去，里面有一行

```
E       assert [0.9062, 0.0625, 0.0312] == [0.9063, 0.0625, 0.0313]
```

模型用了七十七秒，一次改对，没有多改一行。它从 `0.9062` 与 `0.9063` 的差直接想到，内置 `round` 用的是银行家舍入，需要换成十进制的半进位。

第二组只写另有二项外部检查未通过，不给断言。模型用了三百秒，通读全部模块，自己写出整数除法的半进位实现，修好了同一处缺陷。同时它顺手给分页函数加了一条没有任何测试要求的守卫。

第二组才是这道题想观察的行为。第一组没有观察的价值，因为答案已经在提示里。

## 断言里到底有什么

一条失败的断言同时给出了四样东西。哪条测试、什么输入、期望值是多少、实际值是多少。对当前这个任务来说，这四样合起来就是完整的规格。模型不需要理解代码，只需要让实际值等于期望值。

所以失败信息不是线索，它常常是答案。信息量越大，任务越接近抄写。

## 为什么以前不能隐瞒

此前的任务里，可见测试文件就在工作区。模型即使拿不到失败输出，用读取工具打开测试文件，照样能看到全部期望值。隐瞒既拦不住它，又会破坏五个反馈条件之间的可比性，所以那条路走不通。

这次换了难度来源，隐藏测试放在工作区之外，模型读不到。不交断言这招才第一次变得可行。同一件事在不同结构下结论相反，值得记住。

## 对实验设计的含义

要比较五种反馈对修复的影响，第二轮必须留出诊断空间。如果失败信息已经把规格说全，五种反馈都会成功，修复成功率停在百分之百，比较就失去了对象。统计上把这种情况叫天花板效应。

但也不能什么都不给。只写一句有检查没过，模型不知道该往哪看，可能一直找不到，成功率停在零，这叫地板效应。两种极端都测不出条件差异。

## 顺带一个 Python 的坑

`round(0.90625, 4)` 得到 `0.9062`，不是 `0.9063`。Python 的 `round` 采用银行家舍入，恰好一半时取偶数。要得到日常所说的四舍五入，得用 `decimal` 模块的 `ROUND_HALF_UP`，或者自己用整数运算实现。浮点数还不一定精确表示 `0.90625`，所以这类断言最好在十进制下做。

这个坑本身不重要，重要的是它说明了为什么文档字符串里的规则必须逐字兑现。代码能跑、测试能过，不等于符合规格。
